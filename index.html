Unidad 1

Exploración amplia de la arquitectura del computador, los sistemas operativos y los sistemas de enumeración.

Arquitectura del Computador

Concepto: Es la organización lógica y funcional de un sistema informático.

Historia: Su evolución comenzó con máquinas mecánicas y hoy incluye microprocesadores y computadoras modernas.

Características: Incluye CPU, memoria, almacenamiento y periféricos.

Componentes: Procesador, memoria RAM, disco duro, placa base y dispositivos de entrada/salida.

Importancia: Permite comprender cómo funciona una computadora desde su base.

Ventajas: Facilita el diseño, mantenimiento y mejora de sistemas.

Desventajas: Una arquitectura inadecuada puede limitar el rendimiento.

Ejemplos: Computadoras de escritorio, laptops y servidores.

Sistemas Operativos

Concepto: Software que administra recursos y permite interactuar con el hardware.

Historia: Desde los primeros sistemas batch hasta Windows, Linux y macOS.

Características: Gestión de procesos, memoria, archivos y seguridad.

Componentes: Núcleo, controladores, interfaz gráfica y sistema de archivos.

Importancia: Son esenciales para ejecutar programas y administrar el equipo.

Ventajas: Mejoran la eficiencia y la experiencia del usuario.

Desventajas: Pueden consumir recursos y requerir actualizaciones.

Ejemplos: Windows, Linux, Android e iOS.

Sistemas de Enumeración

Concepto: Formas de representar cantidades utilizando diferentes bases numéricas.

Historia: Han evolucionado desde la numeración decimal hasta la binaria usada por los computadores.

Características: Cada sistema tiene una base y símbolos determinados.

Componentes: Dígitos, base y reglas de conversión.

Importancia: Son fundamentales en computación y electrónica digital.

Ventajas: Permiten representar información de forma eficiente.

Desventajas: Requieren práctica para convertir entre bases.

Ejemplos: Decimal, binario, octal y hexadecimal.

Unidad 2

Fundamentos de los algoritmos, los diagramas de flujo y el pseudocódigo como herramientas para resolver problemas.

Importancia de los algoritmos

Definición: Secuencia ordenada de pasos para resolver un problema.

Características: Precisión, finitud, claridad y eficiencia.

Importancia: Son la base del desarrollo de software y la solución de problemas.

Ventajas: Reducen errores y permiten reutilizar soluciones.

Aplicaciones: Búsqueda, ordenamiento, inteligencia artificial y análisis de datos.

Ejemplos: Algoritmo para sumar números o buscar un dato.

DFD (Diagrama de Flujo de Datos)

Definición: Representación gráfica del flujo de información en un sistema.

Características: Muestra entradas, procesos y salidas.

Importancia: Ayuda a entender cómo circula la información.

Ventajas: Facilita el análisis y la documentación.

Aplicaciones: Diseño de sistemas, análisis de procesos y modelación de software.

Ejemplos: Control de ventas o registro de usuarios.

Diagramas de flujo

Definición: Representación visual de un proceso mediante símbolos.

Características: Son claros, secuenciales y fáciles de interpretar.

Importancia: Permiten visualizar el procedimiento antes de programar.

Ventajas: Simplifican la comprensión de procesos complejos.

Aplicaciones: Ingeniería, procesos administrativos y programación.

Ejemplos: Flujo de compra en una tienda o algoritmo de decisión.

Pseudocódigo

Definición: Descripción textual, sencilla y estructurada de un algoritmo.

Características: Usa lenguaje cercano al humano y no depende de un compilador.

Importancia: Es clave para planificar soluciones antes de escribir código real.

Ventajas: Es flexible, claro y útil para aprender programación.

Aplicaciones: Diseño de algoritmos y enseñanza de lógica.

Ejemplos: Pseudocódigo para calcular el promedio de notas.

Unidad 3

Introducción a Python y a los mapas de Karnaugh como herramientas esenciales para la lógica y la programación.

Python

Concepto: Lenguaje de programación de alto nivel, interpretado y versátil.

Historia: Creado por Guido van Rossum en los años 90 y muy usado hoy.

Características: Sintaxis sencilla, legible y multiplataforma.

Importancia: Es fundamental para desarrollo web, ciencia de datos e inteligencia artificial.

Ventajas: Fácil de aprender y con amplia comunidad.

Aplicaciones: Automatización, análisis de datos y desarrollo de software.

Ejemplos: Programa para calcular el área de un círculo.

Mapa de Karnaugh

Concepto: Herramienta gráfica para simplificar expresiones lógicas.

Historia: Desarrollado por Maurice Karnaugh en 1953.

Características: Organiza variables en celdas adyacentes para encontrar grupos.

Importancia: Reduce circuitos lógicos y mejora la eficiencia.

Ventajas: Facilita el análisis de funciones booleanas.

Aplicaciones: Diseño de circuitos digitales y sistemas electrónicos.

Ejemplos: Simplificación de funciones con dos o tres variables.
