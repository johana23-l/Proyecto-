La importancia de los algoritmos en la informática

Los algoritmos permiten resolver problemas de forma lógica, ordenada y eficiente. Son la base para diseñar programas y encontrar soluciones de manera clara y escalable.

Resolución de problemas Optimización Programación

¿Qué es un algoritmo?

Definición

Un algoritmo es una secuencia ordenada de pasos que permite resolver un problema o realizar una tarea de manera precisa.

Características

  • Debe ser preciso.
  • Debe tener pasos ordenados.
  • Debe terminar en un tiempo finito.
  • Debe producir un resultado esperado.

Ejemplo sencillo

Inicio
Leer la hora actual
Si es de mañana, saludar: "Buenos días"
Si es de tarde, saludar: "Buenas tardes"
Si es de noche, saludar: "Buenas noches"
Fin

DFD / Diagrama de Flujo

¿Qué es?

El diagrama de flujo representa visualmente la lógica de un algoritmo mediante símbolos que indican inicio, proceso, decisión y salida.

Símbolos principales

  • Inicio/Fin: marca el comienzo y final del proceso.
  • Proceso: representa una acción o cálculo.
  • Entrada/Salida: muestra datos que se leen o se muestran.
  • Decisión: indica una condición que puede cambiar el camino.

Pseudocódigo

¿Qué es?

El pseudocódigo es una forma de expresar la lógica de un algoritmo con un lenguaje cercano al humano, pero estructurado.

Ejemplo

Inicio
Leer num1
Leer num2
sumar = num1 + num2
Mostrar sumar
Fin

Relación entre algoritmo, DFD y pseudocódigo

Algoritmo: define la lógica y los pasos para resolver un problema.
DFD: representa visualmente esos pasos mediante diagramas y símbolos.
Pseudocódigo: transforma la lógica en una estructura parecida al lenguaje de programación.
