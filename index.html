Arquitectura del Computador

Es la organización lógica y funcional de un sistema informático.

Su evolución comenzó con máquinas mecánicas y hoy incluye microprocesadores y computadoras modernas.

Características: Incluye CPU, memoria, almacenamiento y periféricos.

Sistemas Operativos

Software que administra recursos y permite interactuar con el hardware.

Desde los primeros sistemas batch hasta Windows, Linux y macOS.

Gestión de procesos, memoria, archivos y seguridad.

Sistemas de Enumeración

Formas de representar cantidades utilizando diferentes bases numéricas.

Han evolucionado desde la numeración decimal hasta la binaria usada por los computadores.

Cada sistema tiene una base y símbolos determinados.

Arquitectura del Computador

La arquitectura del computador describe cómo se organizan los componentes físicos y lógicos para que la máquina procese datos.

Se compone de unidad central de proceso (CPU), memoria principal, dispositivos de entrada y salida, y almacenamiento secundario. La CPU interpreta instrucciones, la memoria guarda datos y el bus transporta información entre módulos.

Conceptos clave
  • CPU: Procesa instrucciones y controla los componentes.
  • Memoria RAM: Almacena datos temporales para acceso rápido.
  • Storage: Disco duro o SSD para guardar información a largo plazo.
  • Periféricos: Teclado, mouse, pantalla y otros dispositivos externos.
Ejemplo resuelto

Supongamos que el computador debe ejecutar una suma. El procesador recupera la instrucción, obtiene los operandos de la memoria, realiza la operación y devuelve el resultado a la memoria.

1. Buscar instrucción de suma
2. Cargar valor A desde memoria
3. Cargar valor B desde memoria
4. Ejecutar A + B
5. Guardar resultado en memoria

Sistemas Operativos

Un sistema operativo controla el hardware y ofrece servicios para que las aplicaciones funcionen correctamente.

El sistema operativo administra procesos, memoria, archivos y dispositivos. Sin él, los programas no podrían usar la CPU ni acceder al disco. Además, brinda interfases gráficas y de texto para que el usuario interactúe con el computador.

Funciones principales
  • Gestión de procesos: Controla cuando cada programa se ejecuta.
  • Gestión de memoria: Asigna espacio a aplicaciones y protege datos.
  • Sistema de archivos: Organiza documentos y carpetas.
  • Controladores: Permiten la comunicación con impresoras y cámaras.
Ejemplo resuelto

Imagina que abres un documento. El sistema operativo carga la aplicación, reserva memoria, guarda el archivo temporalmente y muestra la ventana en pantalla.

  3. Explica por qué un sistema operativo debe manejar la memoria de manera eficiente.

Ejercicios propuestos

  2. Haz una lista de servicios que un sistema operativo brinda a los usuarios.

Sistemas de Enumeración

Los sistemas numéricos permiten representar cantidades usando diferentes bases como decimal, binario, octal y hexadecimal.

El sistema decimal es el más usado por las personas, con base 10. Los computadores utilizan el binario, con base 2, porque internamente trabajan con estados de encendido/apagado. Convertir entre estas bases ayuda a comprender mejor los datos digitales.

Ejemplos de conversión
  • Decimal 10 = Binario 1010
  • Decimal 15 = Hexadecimal F
  • Binario 1101 = Decimal 13
Ejemplo resuelto

Convierte decimal 13 a binario:

13 ÷ 2 = 6, residuo 1
6 ÷ 2 = 3, residuo 0
3 ÷ 2 = 1, residuo 1
1 ÷ 2 = 0, residuo 1
Binario = 1101
Ejercicios prácticos
  1. Convierte el número decimal 7 a binario.
  2. Convierte el número binario 1011 a decimal.
  3. Explica por qué los computadores utilizan el sistema binario.

Ejercicios propuestos

  1. Convierte el número decimal 255 a hexadecimal.
  2. Investiga el sistema octal y escribe un ejemplo de conversión.

Unidad 2

Fundamentos de los algoritmos, los diagramas de flujo y el pseudocódigo como herramientas para resolver problemas.

Importancia de los algoritmos

Definición: Secuencia ordenada de pasos para resolver un problema.

Características: Precisión, finitud, claridad y eficiencia.

Importancia: Son la base del desarrollo de software y la solución de problemas.

DFD (Diagrama de Flujo de Datos)

Definición: Representación gráfica del flujo de información en un sistema.

Características: Muestra entradas, procesos y salidas.

Importancia: Ayuda a entender cómo circula la información.

Diagramas de flujo

Definición: Representación visual de un proceso mediante símbolos.

Características: Son claros, secuenciales y fáciles de interpretar.

Importancia: Permiten visualizar el procedimiento antes de programar.

Pseudocódigo

Definición: Descripción textual, sencilla y estructurada de un algoritmo.

Características: Usa lenguaje cercano al humano y no depende de un compilador.

Importancia: Es clave para planificar soluciones antes de escribir código real.

Algoritmos

Un algoritmo es el conjunto de instrucciones que guían la solución de un problema paso a paso.

Todo algoritmo debe ser claro, finito y ordenado. Se puede expresar con palabras, pseudocódigo o diagramas. Los algoritmos son muy útiles para descomponer tareas complejas en acciones simples.

Elementos de un algoritmo
  • Entrada: Los datos iniciales que recibe el proceso.
  • Proceso: Las operaciones o cálculos que se realizan.
  • Salida: El resultado final después de la ejecución.
  • Decisiones: Rutas diferentes según condiciones.
Ejemplo resuelto

Algoritmo para calcular el total de una compra con descuento:

1. Leer precio
2. Leer porcentaje de descuento
3. Calcular descuento = precio × porcentaje / 100
4. Calcular total = precio - descuento
5. Mostrar total
Ejercicios prácticos

  2. Identifica la entrada, proceso y salida en una receta de cocina.
  3. Explica qué significa que un algoritmo sea finito.

Ejercicios propuestos

  1. Diseña un algoritmo para ordenar tres números de menor a mayor.
  2. Redacta un algoritmo para calcular el área de un rectángulo.

Diagrama de Flujo de Datos (DFD)

Un DFD muestra cómo la información se mueve entre entidades, procesos y almacenes de datos.

Este diagrama ayuda a visualizar el flujo de información sin enfocarse en detalles técnicos de implementación. Es útil para entrevistas, análisis de sistemas y comprensión de requerimientos.

Componentes del DFD
  • Entidad externa: Fuentes o destinos de datos.
  • Proceso: Transformación de información.
  • Almacén de datos: Lugar donde se guarda información.
  • Flujo de datos: Conexiones entre componentes.
Ejemplo resuelto

En un sistema de biblioteca, un DFD muestra cómo el usuario solicita un libro, el proceso verifica la disponibilidad y el archivo guarda el registro del préstamo.

Ejercicios prácticos

  2. Explica cómo se representaría el flujo de datos de una orden de compra.
  3. Identifica un proceso y un almacén de datos en un sistema de registro de estudiantes.

Ejercicios propuestos

  1. Dibuja un DFD simple para un formulario de contacto en línea.
  2. Escribe un breve análisis de los datos que se almacenan en un sistema de hospital.

Diagramas de flujo y pseudocódigo

Los diagramas de flujo y el pseudocódigo ayudan a representar algoritmos antes de programarlos.

Un diagrama de flujo usa símbolos con flechas para mostrar el orden de las acciones. El pseudocódigo escribe esos pasos en un lenguaje cercano al humano, sin la sintaxis estricta de un lenguaje de programación.

Diferencias importantes
  • Diagrama de flujo: Visual y secuencial.
  • Pseudocódigo: Texto estructurado con detalles claros.
  • Ambos: Planificación previa a la codificación.
Ejemplo resuelto

Diagrama de flujo para verificar si un número es par o impar y pseudocódigo equivalente:

Inicio
Leer numero
Si numero % 2 == 0 Entonces
  Mostrar "Es par"
Sino
  Mostrar "Es impar"
Fin Si
Fin

  2. Dibuja un diagrama de flujo para decidir si prestar un libro.
  3. Explica qué símbolo del diagrama de flujo sirve para una decisión.

Ejercicios propuestos

  1. Crea un diagrama de flujo para calcular la nota promedio de tres calificaciones.
  2. Redacta pseudocódigo para convertir grados Celsius a Fahrenheit.

Unidad 3

Introducción a Python y a los mapas de Karnaugh como herramientas esenciales para la lógica y la programación.

Python

Concepto: Lenguaje de programación de alto nivel, interpretado y versátil.

Historia: Creado por Guido van Rossum en los años 90 y muy usado hoy.

Características: Sintaxis sencilla, legible y multiplataforma.

Mapa de Karnaugh

Concepto: Herramienta gráfica para simplificar expresiones lógicas.

Historia: Desarrollado por Maurice Karnaugh en 1953.

Características: Organiza variables en celdas adyacentes para encontrar grupos.

Python

Python es un lenguaje ideal para principiantes y profesionales, gracias a su sintaxis clara y su gran cantidad de bibliotecas.

Python permite escribir programas cortos y fáciles de leer. Se usa en desarrollo web, análisis de datos, automatización y ciencias. Su comunidad ofrece herramientas que facilitan el trabajo con datos, gráficos y aprendizaje automático.

Ventajas de Python
  • Sintaxis simple y directa.
  • Gran cantidad de bibliotecas disponibles.
  • Compatible con múltiples plataformas.
  • Excelente para prototipos rápidos.
Ejemplo resuelto

Programa en Python para calcular el área de un rectángulo:

base = float(input("Ingrese la base: "))
altura = float(input("Ingrese la altura: "))
area = base * altura
print("El área es:", area)

Ejercicios propuestos

Mapa de Karnaugh

El mapa de Karnaugh es una técnica visual para simplificar funciones booleanas con menos errores.

Funciona organizando combinaciones de variables en celdas contiguas. Al agrupar unos, se obtienen expresiones más simples. Esto reduce la cantidad de puertas lógicas que se necesitan en un circuito digital.

Pasos para usar un Karnaugh
  • Colocar los valores de la función en la tabla.
  • Agrupar los unos en bloques de 1, 2, 4 o 8.
  • Escribir la expresión simplificada para cada grupo.
  • Unir todas las expresiones con OR.
Ejemplo resuelto

Para la función F(A,B) = Σ(1,3), el mapa de Karnaugh de 2 variables agrupa los unos y simplifica la función a B.

Ejercicios prácticos
  1. Explica qué representa un grupo de unos en un mapa de Karnaugh.
  2. Describe cómo se organiza un mapa de 2 variables.
  3. Enumera beneficios de simplificar una expresión lógica.

Ejercicios propuestos

  1. Resuelve un mapa de Karnaugh para F(A,B,C) = Σ(1,3,5,7).
  2. Investiga cómo se usa Karnaugh en circuitos digitales.
